# Experiment Results

Use the versioned V2 evidence for the current configured experiments. The
strict controlled evidence is a later, additive validation suite. Files under
`archive/` are retained for provenance only and must not be used for current
tables, figures, or scientific claims.

| Status | Location | Contents |
|---|---|---|
| Current configured evidence | [`v2/`](v2/) | Main, equal-NFE, common-control, ablation, scalability, sensitivity, validation, and generated figures |
| Current strict controls | [`raw/`](raw/), [`summary/`](summary/), [`statistics/`](statistics/), [`audit/`](audit/) | Common-population RDHO/RIME/DBO controls, exact-NFE audits, paired statistics, and integrity records |
| Historical only | [`archive/v1.0-paper/`](archive/v1.0-paper/) | Superseded experiment outputs matching the fixed `v1.0-paper` release |
