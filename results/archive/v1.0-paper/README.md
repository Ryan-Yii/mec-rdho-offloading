# V1.0 Paper Experiment Archive

These files match the experiment artifacts published in the fixed
`v1.0-paper` tag and GitHub Release. They are superseded by
[`../../v2/`](../../v2/), retained only for provenance and historical
comparison, and must not be used to regenerate current paper tables, figures,
or claims.

- `raw/`: superseded main, ablation, scalability, task, and convergence rows.
- `summary/`: summaries and tests derived from those superseded rows.
- `sensitivity/`: superseded sensitivity rows, summaries, and figures.
- `figures/`: superseded plots, including the old unversioned radar.

The later strict common-population controls are not part of V1.0 and remain in
the current `results/raw/`, `results/summary/`, `results/statistics/`, and
`results/audit/` directories.
