# v2.0.0 - Audited Physical MEC Offloading Evidence

## Scope

This release is based on the experimental merge commit
`0264b6d35b52bae4ec871ddaf9653285d47a7783`. It contains the complete
capacity-feasible physical-model V2 suite, the additive strict RDHO/RIME/DBO
controls, reproducibility code, raw results, statistics, figures, and aligned
manuscript artifacts.

## Evidence boundaries

- `results/v2/` contains the configured V2 main, equal-NFE, common-control,
  ablation, scalability, and sensitivity suites.
- `results/raw/controlled_*`, `results/summary/controlled_*`, and
  `results/statistics/controlled_*` contain the later strict common-population
  and exact-NFE controls.
- The configured end-to-end RDHO-full advantage has unequal NFE and does not
  establish independent superiority of the hybrid population update.
- Under strict equal controls, RDHO beats RIME but DBO beats RDHO in both the
  population-stage and common-refinement experiments.
- All returned main and strict-control solutions are hard feasible and uniquely
  assigned. No V1 or release1 data are used by V2 generators.
