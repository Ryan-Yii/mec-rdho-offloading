# Paper Tables

- [`v2/`](v2/) contains the current configured V2 manuscript tables.
- Files prefixed with `controlled_` contain the later strict controlled-evidence tables.
- [`archive/v1.0-paper/`](archive/v1.0-paper/) contains the superseded tables from the fixed `v1.0-paper` release.

Current manuscript claims must be traced to `v2/` or to the explicitly named
strict controlled-evidence tables, never to `archive/`.
